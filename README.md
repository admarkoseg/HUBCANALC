# HUB Canal C — mídia do Instagram (@hubcanalc)

Artes e vídeos **aprovados para publicação** no Instagram @hubcanalc.
Os links públicos (raw com SHA do commit, ou GitHub Pages para vídeos) são usados pela publicação via Windsor.ai.

Estrutura:
- `semana-AAAA-MM-DD/<dia>_<tema>/` — `slide_01.jpg`…, `reel.mp4`, `legenda.txt`, `youtube.txt`
- `registro/publicado.txt` — histórico do que foi publicado (data, hora, post, formato, id)

Não colocar aqui material interno nem documentos.
